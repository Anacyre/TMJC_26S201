Design Notes

Style: Minimal, premium, iOS-adjacent. Clear hierarchy, soft shadows, large radius cards, restrained glass blur to feel “lightweight” and modern.

Color logic: Neutral base (white/gray/black) + a single calm blue accent for focus rings and primary actions. This keeps attention on tasks, not decoration.

Why minimal layout: Students log in frequently. A one-screen flow reduces friction and cognitive load—fast entry, no distractions.

Fit for a student task platform: The UI communicates “organized, efficient, reliable” (Tasks/Study/Notifications). The product feels like a tool, not a website.

Interaction design: iOS-like focus glow on fields, tactile button press, smooth theme transition. Register mode is a lightweight state switch—no backend needed.
